01

Why So Loud

Neo-Brutalism grew out of a rebellion against the frictionless, rounded, drop-shadowed sameness of the mid-2010s app. Where that idiom smoothed every edge into a soft grey blur, brutalism does the opposite: it makes the structure loud. A border is not a hairline apology; it is architecture. A shadow does not diffuse; it lands like a stamped block.

The name borrows from the raw poured concrete of architectural Brutalism — béton brut — and carries the same ethic onto the screen: show the material, celebrate the joins, let the system be visibly a system.

What makes it work is honesty under discomfort. The clashing colours and hard geometry are not chaos; they are a strict grammar. Every element sits on the same square grid, wears the same border weight, casts the same offset shadow. Change one geometric constant and the whole page re-tunes together — which is exactly what the Machine Shop lets you do, live.

This showcase is set entirely in the idiom. Turn the page for the six laws, walk the gallery, then retune the geometry yourself.

Six Laws

The grammar is strict. Break the polish, never the system.

1

Structure Exposed

Show the material. Borders, grids, and joins are celebrated, not hidden. The system should be visibly a system.

borders / grid / joins
2

Hard Shadows, No Blur

Shadows are solid offset blocks — a flat colour pushed X and Y, zero blur. They read as physical weight, not atmosphere.

offset / solid / weight
3

Loud, Clashing Colour

Saturated primaries and secondaries set against each other with no gentle gradient between. Contrast is the point.

saturated / clash / contrast
4

Square by Default

Corners are sharp. Radius is zero unless a deliberate, single exception is making an argument. The rectangle is the unit.

radius:0 / rectangle
5

Type as a Brick

Oversized, heavy, uppercase display type poured into the layout as a structural block — not decoration, but load-bearing.

heavy / uppercase / block
6

Deliberate Discomfort

A tilt, a clash, an over-large stamp. The friction is intentional — anti-polish that signals confidence, never accident.

tilt / friction / intent

About

Raw Stock is a single-file, fully live demonstration of Neo-Brutalism — the interface idiom that treats structure as ornament and refuses to smooth its own edges.

Nothing here is a mock-up. Every button lands, every switch flips, the chart answers your cursor, and the Machine Shop rewrites the document's geometry tokens in real time. Type is set in Archivo Black for display, Space Grotesk for body, and Space Mono for the labels and stamps.
